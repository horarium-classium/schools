# Դասացուցակներ

`schools.json` ֆայլում թվարկված են դպրոցները։

Ամեն մի դպրոցի համար նախատեսված է առանձին պանակ հետևյալ ֆայլերով։

- `subjects.json` — առարկաները, (`id`, `title`),
- `teachers.json` — դասատուները, (`id`, `name`),
- `lessons.json` — դասաժամերը, (`number`, `start`, `end`),
- `classes.json` — դասարանները, (`id`, `name`, `schedule`),
- `schedule-*.json` - դասացուցակը՝ ամեն դասարանինն առանձին:
